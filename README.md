# SIWESFlow – Digital Logbook

## About
The Digital Logbook is a feature of SIWESFlow that helps students record and track their SIWES activities and work experience.

## Features
- Submit daily SIWES activities.
- View activity history and details.
- Upload supporting evidence.
- Track total activities and hours spent.
- View activity approval status and supervisor feedback.
- Monitor logbook completion progress.
- View experience verification status.

## Technologies Used
- Next.js
- React
- TypeScript
- Tailwind CSS

## Project Status
The Digital Logbook frontend has been implemented and tested. Backend integration is the next stage.
